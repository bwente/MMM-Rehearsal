# Contributing

Thanks for helping improve MMM-Rehearsal.

1. Create a focused branch from `main`.
2. Keep scripts, certificates, credentials, and personal MagicMirror configuration out of the repository.
3. Run `npm install` and `npm test` before submitting changes.
4. Add or update tests for behavior changes.
5. Keep every translation file aligned with `translations/en.json` when adding user-facing text.

Bug reports should include the MagicMirror² version, operating system, controller browser, relevant configuration with secrets removed, and steps to reproduce the issue.
