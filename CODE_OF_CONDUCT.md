# Code of Conduct

MMM-Rehearsal welcomes people of every background and experience level.

Be respectful, constructive, and considerate. Harassment, personal attacks, discrimination, threats, and publishing someone else's private information are not acceptable in this project.

When giving feedback, focus on the work and explain how it can be improved. Assume good intent, while taking responsibility for the effect of your words and actions.

Project maintainers may edit or remove contributions and restrict participation when behavior is harmful or disruptive. To report a problem, open a GitHub issue with only the information that is safe to share publicly, or contact the maintainer through the GitHub profile linked from the repository.
